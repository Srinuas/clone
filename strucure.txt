# PixelEdit v2

A Flask + OpenCV + Tesseract + PyMuPDF editor for real text replacement.

## What changed

- Supports PDF and common image formats.
- Images are edited at the pixel level using OCR + OpenCV inpainting.
- Replacement text is redrawn into the edited image.
- JPG/JPEG, PNG, WEBP, BMP and TIFF output keeps the same image format.
- PDFs remain PDFs.
- Native PDF text uses PyMuPDF redaction/content editing.
- Scanned/image-only PDF pages can be OCR edited after rendering.
- Modern responsive UI with drag/drop, progress animation and result preview.
- `deploy.sh` is intentionally not included/changed.

## Run with Docker

```bash
docker build -t srinuas/pdfrepo:latest .
docker run -d --name pdfapp -p 3000:3000 srinuas/pdfrepo:latest
```

Then open `http://localhost:3000`.

## Important

OCR-based editing is strongest on clear, horizontal text with reasonable contrast. For arbitrary decorative fonts, handwriting, curved text, complex backgrounds or text overlapping graphics, pixel-perfect reconstruction cannot be guaranteed by OCR alone.
